# 07 — Time Use

## Philosophy

Time is the container for tactics. If tactics are not assigned to specific time slots, they will not happen.

The 12 Week Year is not a to-do list system. It is a **calendar-first** system.

## The Time-Use Audit

Before planning, understand where time currently goes.

**Agent protocol:** Ask the user to estimate hours per week spent on:
- Sleep and personal care
- Work / income generation
- Commute / logistics
- Family / relationships
- Scrolling / passive entertainment
- Unstructured "lost" time

The gap between total hours and allocated hours is the **tactical pool**.

## The Strategic Block

A 3-hour uninterrupted block, scheduled once per week (usually Monday morning).

**Purpose:** High-leverage thinking and planning.
**Rules:** No email, no notifications, no reactive work.
**Agent prompt:** "What 1–2 activities, if done for 3 hours, would create the most progress toward your 12-week goal?"

## The Buffer Block

Two 30–60 minute blocks per day for reactive work: email, messages, admin.

**Rule:** All unplanned tasks go into buffer blocks, not into the middle of deep work.

## The Breakout Block

A 1–3 hour block, 2–3 times per week, for tactics directly tied to 12-week goals.

**This is where the 12-week plan lives.** Each tactic must reside inside a breakout block.

## Calendar Architecture Template

```
Monday
  08:00–09:00  — Weekly Planning Session
  09:00–12:00  — Strategic Block
  12:00–13:00  — Lunch
  13:00–14:30  — Breakout Block (Goal tactics)
  14:30–15:00  — Buffer Block
  15:00–17:00  — Regular work
  17:00–17:15  — Daily execution check

Tuesday–Friday
  08:00–08:30  — Morning routine
  08:30–10:30  — Deep work / Breakout Block
  10:30–11:00  — Buffer Block
  11:00–12:30  — Regular work
  12:30–13:30  — Lunch
  13:30–15:30  — Deep work / Breakout Block
  15:30–16:00  — Buffer Block
  16:00–17:00  — Regular work / wrap-up
  17:00–17:15  — Daily execution check
```

## Agent Time-Use Coaching

When a user misses tactics, the first diagnosis is calendar, not motivation.

**Questions:**
- "Show me your calendar for tomorrow. Where is each tactic scheduled?"
- "If the tactic is not on the calendar, when exactly will you do it?"
- "What is the smallest possible version of this tactic that fits in 15 minutes?"

## Time Use Pitfalls

| Pitfall | Fix |
|---------|-----|
| Tactics on a list, not on calendar | "If it's not scheduled, it's not real." |
| Back-to-back meetings | Demand buffer blocks for tactic protection |
| Perfectionist planning | Use minimum effective dose for calendar blocks |
| Ignoring energy levels | Schedule hardest tactics at peak energy times |
