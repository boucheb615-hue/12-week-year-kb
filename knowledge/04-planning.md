# 04 — Planning

## Planning Discipline Overview

Planning translates vision into executable structure. A plan is worthless without execution, but execution without a plan is chaos.

## Hierarchy of Planning

```
Vision
    ↓
12-Week Goals (1–3 goals max)
    ↓
Tactics (weekly/daily actions per goal)
    ↓
Weekly Plan (scheduled into calendar)
```

## 12-Week Goal Criteria

Each goal must be:
- **Specific** — no ambiguity about what "done" looks like
- **Measurable** — binary or numeric completion criteria
- **Realistic but aggressive** — achievable with high execution, not a fantasy
- **Limited** — 1 primary goal is ideal; 3 is the absolute ceiling
- **Tied to vision** — if accomplished, it must demonstrably advance the 3-year vision

## Tactics Breakdown

Tactics are the weekly and daily actions that produce the goal.

**Types of tactics:**
| Type | Description | Example |
|------|-------------|---------|
| One-time | Completed once during the 12 weeks | "Set up LLC by week 2" |
| Weekly recurring | Repeated every week | "Publish 1 blog post every week" |
| Daily recurring | Repeated most days | "Write 500 words every morning" |

**Tactic rules:**
- 2–5 tactics per goal
- Each tactic should take an assignable block of time
- Must be fully within the user's control (not dependent on luck or others)
- Binary completion (done / not done) whenever possible

## Weekly Planning Ritual (15 minutes every Monday)

1. Review the 12-week goals
2. Identify which tactics are due this week
3. Schedule each tactic into the calendar
4. Anticipate obstacles and plan contingencies

## Agent Planning Checklist

When helping a user create a 12-week plan, verify:
- [ ] Vision is written and emotionally compelling
- [ ] 1–3 goals, each tied to vision
- [ ] Each goal has 2–5 tactics
- [ ] Tactics are specific, time-bound, and controllable
- [ ] Tactics are scheduled in calendar (not just listed)
- [ ] User can articulate what "perfect week" looks like

## Planning Pitfalls

| Pitfall | Fix |
|---------|-----|
| Too many goals | Force priority stack; pick 1 if overwhelmed |
| Result-only tactics ("lose 2 kg") | Reframe into input actions ("track calories daily") |
| Tactics dependent on others | Replace with actions the user controls |
| No calendar scheduling | "If it's not scheduled, it's not real." |
