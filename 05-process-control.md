# 05 — Process Control

## What is Process Control?

Process control is the system of rituals and structures that ensures the plan is executed consistently. It is the bridge between planning and results.

Without process control, plans become wish lists. This discipline prevents drift.

## Core Rituals

### 1. The Weekly Accountability Meeting (WAM)
**Duration:** 15 minutes, same day/time every week.  
**Purpose:** Review last week's score, recommit, plan the upcoming week.

**Agenda template:**
1. What was your execution score last week? (0–100%)
2. What tactics did you miss? Why?
3. What will you do differently this week?
4. What obstacles do you anticipate?
5. State your commitment for the upcoming week out loud.

**Agent equivalent:** Simulate this every week with the user via chat or voice.

### 2. Weekly Planning Session (15 minutes Monday)
Before the week begins, schedule every tactic into the calendar.

**Steps:**
1. List all tactics due this week from the 12-week plan.
2. Block specific times on the calendar for each tactic.
3. Protect the blocks (treat them as unmovable meetings).
4. Review for conflicts; adjust if needed.

### 3. Daily Execution Check
**Duration:** 2 minutes  
**Timing:** End of each day

**Questions:**
- Did I complete today's tactics? (yes/no)
- If not, what got in the way?
- What is the first tactic tomorrow morning?

### 4. The Break Week Ritual (Between cycles)
**Purpose:** Recovery, reflection, light planning for next cycle.

**Activities:**
- Rest and celebrate progress
- Review results and execution scores from the cycle
- Update vision if needed
- Draft next cycle's 12-week plan (high-level only)

## Process Control Tools

| Tool | Purpose |
|------|---------|
| Calendar blocks | Time protection for tactics |
| Weekly scorecard | Track tactic completion |
| Commitment statement | Verbal or written reaffirmation |
| Accountability partner | External commitment device |
| Agent (you) | Weekly check-in, obstacle diagnosis |

## Common Failure Modes

| Failure | Process Control Fix |
|---------|--------------------|
| "I forgot" | Calendar alerts + daily check-in |
| "I didn't have time" | Time audit + block redesign |
| "I wasn't motivated" | Reconnect to vision + reduce friction |
| "Something came up" | Contingency tactics + buffer time |

## Agent Process Control Protocol

When interacting with the user mid-cycle:
1. **Never ask open-ended** "How is it going?" Ask: "What is your execution score so far this week?"
2. **If score < 80%:** Diagnose the top obstacle. Do not accept excuses; identify the friction point.
3. **If score < 50%:** Trigger emergency protocol — reduce scope, re-negotiate goals, or restart with a simpler plan.
4. **If score = 100%:** Celebrate and warn against adding extra goals ( protect the system ).
